# 2to51CL-FF
This is a Windows x64 Command Line utility that uses the ffmpeg library and the libfftw3-3 library to import a stereo audio file and export a multichannel 5.1 audio file in the standard L R C LFE Ls Rs layout.
Clone the repository to your computer. Open a Visual Studio x64 Developer Command Prompt. Navigate to the repository. Run compile-ff.bat. Put the executable and all the dll files in the "dll" folder into the same installation folder on your computer. Run "2to51CL-FF.exe" to see the help menu.
